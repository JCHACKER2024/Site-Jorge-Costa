# Portfólio de Game Development - Jorge Costa

Bem-vindo ao meu portfólio pessoal! Este projeto foi desenvolvido para apresentar as minhas competências em **Modelação 3D**, **Criação de Ambientes** e **Desenvolvimento de Jogos**.

## Funcionalidades do Site

- **Modo Escuro/Claro:** Sistema de tema dinâmico que guarda a preferência do utilizador no navegador (`localStorage`).
- **Showcase de Projetos:** Galeria interativa com sliders para cada projeto realizado (Bubble, Color Morph, Cursed Revenge).
- **Integração com API Real:** Na página de jogos favoritos, o site consome a API da *CheapShark* para mostrar sugestões de jogos semelhantes com **preços atualizados em tempo real**.
- **Design Responsivo:** Totalmente adaptado para dispositivos móveis e desktops.

## Tecnologias Utilizadas

- **HTML5 & CSS3:** Estrutura e estilização avançada com animações e efeitos de blur.
- **JavaScript (ES6+):** Lógica dos sliders, manipulação do DOM e consumo de APIs assíncronas (`fetch` e `async/await`).
- **GitHub Pages:** Alojamento e deploy automático.

## Foco Criativo

O meu trabalho foca-se na criação de assets otimizados para motores de jogo como **Unreal Engine** e **Unity**, especializando-me em:
- Modelação Low/Medium Poly.
- Texturização e UV Mapping.
- Level Design e Iluminação de Ambientes.
